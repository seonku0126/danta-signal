# 단타 시그널 봇 (GitHub Actions 버전)

맥북도 서버도 필요 없습니다. GitHub가 매일 대신 실행하고, 텔레그램 비공개 채널 **"단타 시그널"**(봇 @seonku_danta_signal_bot)에 올립니다. 시세는 네이버 증권 공개 데이터를 쓰므로 증권사 키나 IP 등록이 필요 없습니다. 주문 기능은 없습니다.

## 하루 흐름

| 시각 (KST) | 내용 |
|---|---|
| 08:40 | cron-job.org가 `morning` 워크플로를 깨움 (예비로 08:41 GitHub 예약도 있음, 중복 실행은 자동 차단) |
| 08:45 | 아침 공지와 누적 성적 + 🔔 **장전 관심종목** (넥스트레이드 프리마켓 가격 기준, 어제 주도주 중 갭 +2~12%) |
| 09:05 | 🎯 **오늘의 종목 확정** (매일 반드시 1종목, 선정에 약 4초) |
| 확정 후 | **실시간 추적**: 3초마다 현재가 확인. 손절·목표·+3%/+5% 알림 |
| 09:16 | 오늘 아침 거래대금 상위 400종목 분봉을 `data/minutes/`에 저장 (백테스트용) |
| 14:30 | cron-job.org가 `afternoon` 워크플로를 깨움. 14:20~14:30 공백 구간은 1분봉으로 확인한 뒤 이어서 추적 |
| 15:20 | 남아 있으면 청산 처리 |
| 15:35 | 📊 마감 리포트: 오늘 결과, 관심종목 결과, 최근 5거래일, 이번 달·전체 누적, 관심종목 적중률 |

수능날처럼 개장이 늦은 날은 실제 개장을 확인한 뒤 그때부터 10분 스캔합니다. 휴장일은 자동으로 종료합니다.

## 고르는 기준 (danta/strategy.py) — 2026-11-26 백테스트로 교체

**규칙**: 09:05에 상승률 +2~15%, 현재가가 VWAP·시가 위인 종목 중 **09:01~09:04 거래대금(동시호가 제외) 1위**.
조건 통과 종목이 없으면 단계적으로 완화해서 매일 1종목은 반드시 고릅니다. 완화로 고른 날은 메시지에 표시합니다.
손절은 VWAP 아래 2~4%, 목표는 손절폭 × 2입니다.

**백테스트 요약** (`scripts/fetch_hist.py` → `scripts/research.py`)
- 데이터: 야후 2분봉 32거래일, 5분봉 60거래일. 후보군은 **전일** 거래대금 상위 400(사후 정보 제거). 다음 봉 시가 진입, 비용 0.35% 차감.
- 선정 12종 × 진입 시각 7종 × 청산 15종 = 1,260조합을 비교했습니다.
- **09:04~09:06 진입 + 초반 거래대금 1위**: 15개 청산 규칙 중 13개에서 플러스.
  - 현재 청산(손절폭×2) 기준 09:04는 32회 +26.8%(1회 평균 +0.84%), 09:06은 +39.4%(평균 +1.23%).
  - 전반·후반 모두 플러스였습니다.
- **09:10 이후 진입은 모든 선정 방식이 마이너스**였습니다. 이전 점수식은 60일 동안 -22% ~ -90%였습니다.
- 네이버 1분봉으로 최근 6거래일을 재확인한 결과는 -3.0%(2승 4패)로, 최근 1주는 약했습니다.
- 표본이 작아서(32일) 앞으로도 수익이 난다는 보장은 없습니다. `data/minutes/`에 쌓이는 분봉으로 계속 재검증하세요.

## 설정 (한 번만)

1. **Secrets**: 저장소 Settings → Secrets and variables → Actions에 아래를 넣습니다.
   - `TELEGRAM_BOT_TOKEN`: BotFather 대화방의 토큰
   - `TELEGRAM_CHAT_ID`: 비워 두면 봇이 추가된 채널을 자동으로 찾습니다. Actions → test-telegram 실행 로그에 나온 `-100…` 값을 넣어두면 확실합니다.
2. **테스트**: Actions → test-telegram → Run workflow를 실행하고 채널에 메시지가 오는지 확인합니다.
3. **정시 실행 (cron-job.org)**: 두 작업을 만듭니다.
   - URL: `POST https://api.github.com/repos/<계정>/<저장소>/actions/workflows/morning.yml/dispatches` (afternoon은 `afternoon.yml`)
   - 헤더: `Authorization: Bearer <GitHub 토큰>`, `Accept: application/vnd.github+json`
   - 본문: `{"ref":"main"}`
   - 시각: 월~금 08:40 / 14:30, 시간대 Asia/Seoul
   - GitHub 토큰은 Fine-grained로 만들고, 이 저장소만 선택한 뒤 **Actions: Read and write** 권한만 줍니다.

## 점검·백테스트

```bash
pip install -r requirements.txt
python -m danta.gh scan-once           # 지금 시장 후보·점수·탈락 사유
python scripts/backtest.py --days 10   # 최근 분봉으로 재현 (네이버는 약 1주일치만 보관)
```

`data/minutes/`에 매일 분봉이 쌓이므로, 몇 주 뒤에는 이 데이터로 더 긴 백테스트를 돌릴 수 있습니다.

> 투자 참고용 자동 시그널입니다. 과거 기록이 미래 수익을 보장하지 않습니다. 이 저장소는 공개라서 코드와 `data/` 기록을 누구나 볼 수 있습니다(텔레그램 토큰 같은 Secrets는 보이지 않음). 네이버 데이터는 공식 API가 아니어서 구조가 바뀌면 `danta/naver.py`를 고쳐야 합니다.
